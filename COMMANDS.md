## 1. Prefix

| Hal                   | Nilai                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| Prefix default        | `owo` (huruf kecil semua, `config.prefix`)                                    |
| Override global       | env `PREFIX` (mis. `PREFIX=s!`)                                               |
| Prefix per-server     | `owo prefix <baru>` — butuh permission **Manage Channels**, disimpan di Redis |
| Reset ke default      | `owo prefix owo` (menghapus prefix server)                                    |
| Melihat prefix server | `owo prefix` tanpa argumen                                                    |
| Batasan prefix kustom | maksimal 25 karakter ASCII, tanpa mention, otomatis di-lowercase              |
| Mention bot sendiri   | bukan prefix                                                                  |

Bentuk pemanggilan: **`<prefix><command> [argumen]`**, contoh:

```
owo hunt
owo battle @user
s! daily            (kalau server memakai prefix "s!")
```

### Prefix pendek (contoh nyata `w`)

Banyak server memakai prefix satu huruf, misalnya `w`, lalu memakai **alias**
command-nya. Karena prefix dan alias digabung tanpa spasi, hasilnya terlihat
seperti "command baru" padahal bukan:

| Yang diketik | Diurai menjadi | Command asli                                                                  |
| ------------ | -------------- | ----------------------------------------------------------------------------- |
| `wb`         | `w` + `b`      | `battle` (alias `battle`, `b`, `fight`)                                       |
| `ws 100000`  | `w` + `s`      | `slots` (alias `slots`, `slot`, `s`)                                          |
| `wh`         | `w` + `h`      | `hunt` (alias `hunt`, `h`, `catch` → `zoo/catch`)                             |
| `wcash`      | `w` + `cash`   | `cowoncy` (alias `cowoncy`, `money`, `currency`, `cash`, `credit`, `balance`) |

Tidak ada command terpisah bernama `ws`, `wh`, atau `wcash`; semuanya adalah
prefix + alias. Kalau server memakai prefix default, bentuk lengkapnya
`owo slots 100000`, `owo hunt`, dan `owo cash`.

Catatan:

- Pesan yang hanya berisi `owo` atau `uwu` (tanpa command) dijawab oleh command
  `points` — ini perilaku lama yang dipertahankan.
- Prefix juga dibaca di DM: pesan DM harus diawali prefix agar diproses.
- **Command staff/owner** juga memakai prefix yang sama, tetapi hanya berfungsi
  di channel yang terdaftar di `MOD_CHANNEL_IDS`. Tanpa konfigurasi itu, command
  staff tidak dijalankan di mana pun.
- Ada 14 command yang juga didaftarkan sebagai **slash command**
  (`/battle`, `/crate`, `/eject`, `/emergency`, `/headpat`, `/waddle`,
  `/emoji`, `/level`, `/profile`, `/avatar`, `/color`, `/help`, `/hunt`,
  `/lootbox`).
